# Proposito del Repositorio
Este repositorio funciona como evidencia de clase y portafolio digital para almacenar todas las practicas, ejercicios y proyectos desarrollados a lo largo del curso.

# Estructura del Repositorio
- `practicas/`: Contiene los ejercicios practicos de la materia, incluyendo las traducciones de bloques de Scratch a codigo de Python.
- `proyectos/`: Contiene los proyectos principales y entregas integrales del curso.

# Bitacora de Instalacion del IDE
- **Herramienta instalada:** Visual Studio Code y Git.
- **Version:** Version mas reciente de VS Code y Git para Windows.
- **Problemas y soluciones:** Durante la instalacion no hubo mayores contratiempos con el IDE, sin embargo, al configurar Git por primera vez fue necesario verificar la terminal y asegurar el uso correcto del nombre de usuario y correo electronico vinculados a la cuenta de GitHub para autenticar los cambios de forma exitosa.

# Instrucciones para Clonar y Usar el Repositorio
Si quieres clonar este repositorio en tu computadora, sigue estos pasos:
1. Abre tu terminal o Visual Studio Code.
2. Copia el enlace HTTPS del repositorio desde GitHub.
3. Ejecuta el comando de clonacion o usa la opcion *Git: Clone* en VS Code pegando el enlace.
4. Explora las carpetas `practicas/` y `proyectos/` para revisar el contenido.
